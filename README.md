┌─────────────────────────────────────────────────┐
│  三步开始用                                      │
└─────────────────────────────────────────────────┘

  1️⃣   把 Refina 拖进「应用程序」
       （打开 Refina.dmg 就会看到箭头，跟着拖）

  2️⃣   第一次打开：右键点 Refina → 「打开」→ 再点「打开」
       ⚠️  一定要右键！直接双击会被 macOS 拦下来。
           只需要做这一次，之后正常双击。

           macOS 15 或更新的另一条路：
           双击被拒 → 系统设置 → 隐私与安全性
           → 拉到最下面 → 点「仍要打开」

  3️⃣   用 Google 登录一次
       （之后断网也能用，登录只是为了存你的成就）


┌─────────────────────────────────────────────────┐
│  能做什么                                        │
└─────────────────────────────────────────────────┘

  🎬  影片    慢动作（最高 32 倍）· AI 放大 · 降噪
  🖼️  照片    去噪 · 放大 · 人脸修复 · 黑白上色
  🎙️  音频    去噪 · 修音色 · 响度归一 · 左右分轨

  用法：进去选一个 → 把文件拖进来 → 选预设 → 按开始
  输出存在原文件旁边，原档不会被动到。


┌─────────────────────────────────────────────────┐
│  你的电脑够不够跑                                │
└─────────────────────────────────────────────────┘

  ✅  macOS 13 Ventura 或更新
  ✅  Apple Silicon（M1 / M2 / M3 / M4）
  ❌  Intel Mac 不支持
  💾  硬盘留 5 GB（App 2.6 GB + 处理时的临时文件）
      4K 慢动作要更多：8 倍约 20 GB，32 倍约 80 GB
      临时文件跑完自动删
  🧠  内存 8 GB 够跑 1080p；4K 慢动作建议 16 GB


┌─────────────────────────────────────────────────┐
│  大概要等多久（M1 Max 实测）                     │
└─────────────────────────────────────────────────┘

  🎙️  音频去噪「快」      1 分钟音频 → 7 秒
  🎙️  音频去噪「精细」    1 分钟音频 → 20 秒
                          （首次会下载 211MB 模型）
  🖼️  照片去噪 + 放大     一张 1200 万像素 → 20 秒
                          修脸 +8 秒，上色 +10 秒
  🎬  慢动作 / 补帧       每帧约 0.15 秒
                          （10 秒 30fps 的片 → 约 1 分钟）
  🎬  AI 放大影片         每帧约 12 秒（很慢，只建议短片段）


┌─────────────────────────────────────────────────┐
│  几个要知道的事                                  │
└─────────────────────────────────────────────────┘

  ⚠️  只丢「没剪过」的单条素材。剪好的成片在镜头
      切换那一帧会出鬼影。
  📁  输出跟原文件放一起，也可以自己指定文件夹。
  🔒  你的影片照片音频不会上传到任何地方。
  🆕  有新版本时，App 右上角会自己出现橙色按钮，
      点一下就更新好（十几 MB，几秒钟）。
  🐛  用到问题，点右上角那只虫子告诉我。
